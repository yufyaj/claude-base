## 実装時の遵守事項
* SOLID原則に従う
* 既存の処理に重複した処理を記述しない
* マジックナンバーや固定文字列はハードコーディングしない
* APIキー、パスワード等の機密情報はコードに含めず、環境変数を使用する
* 重複コードは共通処理として抽出する
* OWASP準拠する
* 入力バリデーションを実施する
* 不要なログは本番コードに残さない
* エラーハンドリングはexception_handlerを使用してください
* type: ignoreで型チェックを回避せず、正しい型を使え
* 広範な例外をキャッチしてエラーメッセージをそのまま外部に返すな
* リント・型チェック・バリデーションの警告を抑制するな。コードの方を直せ。設定ファイルの変更が必要な場合は確認を取れ。
